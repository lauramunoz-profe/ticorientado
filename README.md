# Sistema finalizado – Promoción 6.º Año

Sitio estático para GitHub Pages. No requiere instalación ni dependencias.

## Verlo en tu computadora
1. Descomprimí el archivo.
2. Abrí `index.html` con Chrome, Edge o Firefox.

## Publicarlo en GitHub Pages
1. Creá un repositorio en GitHub, por ejemplo `despedida-6to`.
2. Subí al repositorio los tres archivos: `index.html`, `styles.css` y `script.js` (también podés subir este README).
3. En el repositorio, entrá a **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`. Guardá.
6. Esperá a que GitHub publique el sitio. La dirección tendrá este formato:
   `https://TU-USUARIO.github.io/despedida-6to/`

## Personalización
- El año aparece en el diploma y puede cambiarse en `index.html`.
- El mensaje está dentro de la sección `letterText` de `index.html`.
- Los colores y efectos están en `styles.css`.
- La animación inicial y las partículas están en `script.js`.

El botón del diploma abre la ventana de impresión del navegador. Elegí **Guardar como PDF** para conservarlo.
